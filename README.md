# Sony WH-1000XM6 — Cinematic Scrollytelling Experience

An Apple/Awwwards-level cinematic product reveal and interactive engineering showcase for the **Sony WH-1000XM6** flagship wireless noise cancelling headphones.

---

## ✨ Features

- **120-Frame Scroll-Linked Canvas Animation:** Buttery-smooth HTML5 Canvas image-sequence animation with momentum lerp rendering that dismantles the headphones into an exploded technical diagram and reassembles them upon scroll.
- **Seamless Void Aesthetic:** Calibrated to pure deep charcoal `#050505` with feathered radial blending for an edge-free presentation.
- **Interactive Audio DSP Simulator:** Live Web Audio API synthesizer demonstrating Active Noise Cancelling (-42 dB), Ambient Sound Transparency, and Hi-Res Audio LDAC with live decibel attenuation meters.
- **Hardware Architecture Dossier:** Sci-fi terminal exploring the 40mm carbon-composite driver, QN2 + V2 dual silicon architecture, 12-microphone beamforming cluster, and memory foam cushions.
- **Customizable Studio EQ:** Interactive 5-band parametric equalizer with dynamic 3D wireframe mesh oscilloscope curve and Clear Bass™ control.
- **Materials & Colorway Studio:** Interactive 8K macro render switcher (*Obsidian Matte Black, Platinum Silver, Midnight Navy*).
- **First Edition Reservation Drawer:** Interactive pre-order modal with finish selector, laser engraving customization, and unboxing inventory.

---

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Audio:** Web Audio API (real-time DSP synthesis & biquad filtering)
- **Rendering:** HTML5 Canvas 2D Context with `requestAnimationFrame` interpolation

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/sorathiya-nagma/sony-wh1000xm6.git
cd sony-wh1000xm6
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
